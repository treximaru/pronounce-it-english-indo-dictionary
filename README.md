# English Dictionary: Pronounce It!

An **offline English–English dictionary** Android app built for Indonesian
vocational-school students, with one main focus: **pronunciation**.

Look up a word and get its IPA transcription (UK first), syllable breakdown
with stress marks, an English definition, an example sentence, an Indonesian
meaning (when available), and tap-to-hear audio for both the word and the
example — all without an internet connection for the dictionary data.

> *Proudly presented for the Four Pillars English Club of Panca Bhakti
> Vocational High School*
>
> Developed by **Muhammad Abdul Aziz, S.Pd**

Current release: **1.7.0-beta** (Android, arm64)

---

## Features

- **91,556 words**, fully offline in a bundled SQLite database
- **One primary IPA per word, UK priority** — UK → untagged Wiktionary → US,
  so accents never get mixed up or silently swapped
- **Syllable + stress display** (from CMUdict) with the stressed syllable
  highlighted
- **Indonesian meanings** for 22,369 words (24.4%), shown before the English
  definition
- **Synonyms & antonyms** at the bottom of each word page — synonyms in
  green, antonyms in red, each a tappable chip that jumps to that word
  (33,056 words with synonyms, 7,993 with antonyms)
- **Listen / Slow / example audio** using the device's built-in TTS (en-GB)
- **Keyboard always ready** — the search field autofocuses on open, after
  returning from a word, and after clearing
- Fast search — the exact word you type always comes first, then prefix
  matches by frequency — with a one-tap clear (✕) button
- **Light / Dark / Follow-system theme** — tap the theme icon in the top bar
  to cycle; the choice is saved and kept across restarts
- No accounts, no ads, no tracking; dictionary data never leaves the phone

## Dataset pipeline

The database (`kamus_v24.sqlite`, ~35 MB) is generated by the scripts in
`scripts/` and is **not stored in git** (too large); regenerate it with:

```bash
python3 -m venv .venv && .venv/bin/pip install nltk wordfreq

# 1) Prototype set: top-1,000 frequent words + WordNet + CMUdict
.venv/bin/python scripts/build_dataset.py        # -> data/kamus_prototype.sqlite

# 2) Full enrichment from the Kaikki English Wiktionary dump (~3.4 GB)
curl -O https://kaikki.org/dictionary/English/kaikki.org-dictionary-English.jsonl
mv kaikki.org-dictionary-English.jsonl data/kaikki-en.jsonl
.venv/bin/python scripts/enrich_kaikki.py        # -> data/kamus_v2.sqlite

# 3) Indonesian glosses from WordNet Bahasa (needs NLTK wordnet + omw-1.4
#    corpora under NLTK_DATA, see the script header)
.venv/bin/python scripts/merge_gloss_wordnet_bahasa.py   # -> data/kamus_v22.sqlite

# 4) Synonyms & antonyms from Wiktionary senses + WordNet fill
.venv/bin/python scripts/add_synonyms_antonyms.py        # -> data/kamus_v23.sqlite

# 5) Syllable/stress gap-fill from Britfone (MIT; data/britfone.main.3.0.1.csv
#    downloaded from https://github.com/JoseLlarena/Britfone)
.venv/bin/python scripts/merge_britfone_stress.py        # -> data/kamus_v24.sqlite
```

Coverage of the final dataset: 91,556 words; IPA UK 36,725 (40.1%),
any-IPA 100%; example sentences 61,138; Indonesian glosses 22,369 (24.4%);
synonyms 33,056 (36.1%); antonyms 7,993 (8.7%); syllables & stress 33,730
(36.8%, incl. 361 British fills from Britfone, MIT).

> Note: an Indonesian-Wiktionary route for extra glosses was tried and is a
> dead end — its Kaikki dump contains only Indonesian headwords, no English
> entries. WordNet Bahasa is what actually works.

## Build from source

Requirements: Flutter 3.47.7 (Dart 3.13.5), JDK 17, Android SDK
(platforms 35/36).

```bash
cp data/kamus_v24.sqlite app/assets/kamus_v24.sqlite
cd app
flutter pub get
flutter build apk --release --split-per-abi
# -> app/build/app/outputs/flutter-apk/app-arm64-v8a-release.apk
```

The app (`app/lib/main.dart`, single-file) copies the bundled SQLite asset to
app storage on first run under a versioned filename, searches with an
exact-match-first, prefix-then-frequency query, and renders the detail page
with TTS via `flutter_tts` and database access via `sqflite`.

**Signing:** official builds are signed with the project's permanent release
keystore, wired in `app/android/app/build.gradle.kts` through
`app/android/key.properties` (the keystore and that file are kept outside git
— never commit them). Without `key.properties`, a build falls back to the
debug key. Since the 2026-10-24 rebuild, all release APKs use the permanent
key, so new versions install directly over the previous one.
